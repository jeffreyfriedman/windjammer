The first line holds N. Each of the next N lines holds two integers `a b` (a <= b) describing the closed interval [a, b].

Intervals are closed. Merge every pair of intervals that share at least one point (so [1,3] and [3,5] merge into [1,5], but [1,3] and [4,5] stay separate). Print the merged intervals sorted ascending, one `a b` per line. If N is 0 print nothing.
