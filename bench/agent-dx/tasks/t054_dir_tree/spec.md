Walk the current directory recursively and print a tree. Directories and files are listed together, sorted by name ascending (bytewise). Each entry is printed on its own line indented by two spaces per depth level (depth 0 entries have no indent). A directory prints as `name/` and is followed by its contents one level deeper; a file prints as `name (<size> bytes)` using its size in bytes (`1 byte` is NOT special-cased: always `bytes`). Empty directories are not representable by the tests (every directory contains a file), and there are no symlinks. After the tree print `<d> directories, <f> files`, counting every directory and file encountered (the root itself is not counted).
