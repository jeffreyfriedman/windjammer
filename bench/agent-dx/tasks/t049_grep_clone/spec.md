Write a minimal `grep`. Arguments: any mix of flags `-i` (ignore ASCII case), `-n` (prefix matches with `<line number>:`), `-c` (print only the number of matching lines), `-v` (invert the match), a PATTERN (the first non-flag argument) and then one or more FILE names. The pattern is a plain substring, not a regex. Flags may appear anywhere. Argument `--` is not used.

For each file in order, print matching lines. With more than one FILE, prefix every output line with `<file>:` (before the line number if `-n` is also given). With `-c` print `<count>` per file (prefixed with `<file>:` when there are several files) instead of the lines. A file that cannot be read prints `grep: <file>: No such file` and sets the exit status to 2. Otherwise the exit status is 0 if at least one line matched in total (for -v: at least one non-matching line), else 1. With -c the status rule still counts matched lines.
