Arguments: `FILE COLUMN OP`. FILE is a CSV file whose first line is a header of column names (no quoting, no spaces; fields separated by commas). The remaining lines are records. COLUMN is a column name. OP is one of `sum`, `min`, `max`, `count`, `mean`.

Compute OP over the values of COLUMN across all records and print the integer result. `count` counts records (any value). The other ops parse each value as a non-negative integer; `mean` is the integer (floor) average, and if there are no records `sum`/`count` print 0 while `min`/`max`/`mean` print `n/a`. If a value is not a valid non-negative integer print `error: bad value <value> on line <n>` (n = 1-based line number in the file, header = line 1) and exit 3 (check rows in order; the first bad value wins; `count` never fails on bad values). If the file is missing print `error: cannot read <FILE>` and exit 1; if the column does not exist print `error: no such column <COLUMN>` and exit 2; unknown OP prints `error: unknown op <OP>` and exits 2 (checked after the column). Rows shorter than the header lacking the column count as the empty string (a bad value for the numeric ops).
