Maintain a sequence of integers (implement it as a singly linked list if you like). Commands, one per line:

- `push_front x`, `push_back x` : add x. Print nothing.
- `pop_front`, `pop_back` : remove and print the element, or print `empty`.
- `remove x` : remove the first occurrence of x; print `removed` or `missing`.
- `reverse` : reverse the sequence in place. Print nothing.
- `print` : print the elements separated by spaces, or `<empty>`.
- `nth k` : print the 0-based k-th element, or `none` if out of range.
