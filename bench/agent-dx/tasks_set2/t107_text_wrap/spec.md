The first input line is the width W (a positive integer). The remaining input is text. Split the text into words on whitespace (spaces, tabs, newlines) and re-flow it greedily: put as many words as fit on a line with single spaces between them and total length at most W; a word longer than W gets its own line unbroken. Print the lines. Empty text prints nothing. Input where the first line is not a positive integer prints `error: bad width` and exits with status 1.
