The first line holds `R C` (rows, columns; both between 1 and 20). The next R lines hold C integers each, separated by spaces. Print the matrix elements in clockwise spiral order starting from the top-left corner, separated by single spaces, on one line. If the input is malformed (first line not two positive integers, fewer than R rows, a row without exactly C integers) print `error` and exit with status 1.
