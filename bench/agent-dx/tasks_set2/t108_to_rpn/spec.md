Each input line is an infix expression over non-negative integers, the binary operators `+ - * / ^` and parentheses, with optional spaces. Print the postfix (reverse Polish) form with tokens separated by single spaces. Precedence from high to low: `^` (right-associative), then `*` and `/`, then `+` and `-` (all left-associative); parentheses group. A line that is not a valid expression (unbalanced parentheses, missing operand or operator, unknown character) prints `error`. Blank lines are skipped.
