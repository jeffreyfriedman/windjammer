# Test-adjacent files that no runner reaches on purpose. Format: <glob> | <reason>
# `*` does not cross `/`; `**` does. Fixtures and helpers only; real tests must be wired or deleted.
tests/conformance/run_conformance_tests.sh | manual end-to-end runner (rustc + execute); the compile stage is covered by tests/wj_corpus_test.rs
tests/cli_gate_*.sh | manual red/green emit gates that need a built `wj` (WJ env var)
tests/reproducibility_test.sh | manual determinism probe; needs a game project path (WJ_GAME_DIR)
tests/run_red_repro_bundle.sh | manual driver that runs the red-repro filters listed in the script
std/basic_test.wj | stdlib self-test module, run by `wj test std` (user-facing `wj test` target, not a cargo test)
std/test_simple.wj | stdlib module-resolution fixture (no test functions), imported by `wj test` layout checks
examples/syntax_tests/** | example package whose tests are run by `wj test examples/syntax_tests`
examples/tests/** | example package whose tests are run by `wj test examples`
tests/fixtures/formatter/* | golden input/expected pairs read by directory in tests/formatter_golden_test.rs
tests/fixtures/resolve/* | resolver fixtures read by directory in tests/resolve_fixtures_test.rs
tests/py_ports/** | fixture trees and recorded expectations for the Windjammer script ports (scripts/wj/port_gates.wj)
