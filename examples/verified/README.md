# Verified example corpus

Small idiomatic Windjammer programs whose output is checked in CI (`tests/verified_examples_test.rs`).
Prefer these over memory when you need the syntax of an idiom: `wj docs <topic>` searches them.

Header lines (all `//` comments at the top of the file):

| Header | Meaning |
|--------|---------|
| `// tags: a, b` | retrieval tags (see `manifest.json`) |
| `// allow: fs.read=/tmp/**` | a capability the program needs under `wj run` (repeatable; ADR-0021: the default sandbox allows only the project directory) |
| `// expect: text` | one line of expected stdout, in order; an oracle derived independently of the interpreter (by hand or a Python model) |
| `// exit: N` | expected exit status (default 0; panics are 101) |
| `// rust: ok` | also compiled with `wj build --no-cargo` + `rustc`; output must equal the `expect` lines |
| `// rust: gap <why>` | known compiled-path gap (recorded, not hidden; the test only reports when it is fixed) |
| `// tests-passed: N` | for `*_test.wj`: `wj test --interpret` must report N passed |

Every program is also lint-clean (`wj lint --strict`: no `.iter()`, `.unwrap()`, explicit `&` arguments or `.clone()`).
`manifest.json` is generated by `wj agent-index` and checked for drift by the test.
