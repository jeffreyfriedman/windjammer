## Maintenance rules
- Delete stale documents; git history is the archive. Keep a document only if it is true, or is a design with a status banner.
- No session/status/summary files. User-visible changes go in CHANGELOG.md.
- No performance or "N tests passing" claims without a command that reproduces them.
