# Windjammer for IntelliJ-based IDEs

There is no IntelliJ plugin in this repository. Use an LSP plugin such as LSP4IJ and register the `windjammer-lsp` binary
(built from [crates/windjammer-lsp](../../crates/windjammer-lsp/README.md), speaks LSP over stdio) as the language server for `*.wj` files.
